## 运行环境
这个系统的运行环境只有一台机器，配置如下：
1. CPU：ARMv7 4核 32位
2. 内存：1G
3. 操作系统：威联通NAS
4. 使用docker，docker compose

## 技术栈
因为运行机器的性能配置过低，所以所有代码均要求以**最省资源的形式**去编写，严格遵循**以时间换空间的概念**，具体技术要求如下：
1. 运行时：nodejs 22
2. 编写语言：TypeScript
3. web框架：HyperExpress 
4. 前端框架：纯html + css + js

## 代码要求
1. 所有的代码都要求有极致的性能
